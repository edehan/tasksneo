## 2026-03-17 — Auth Baseline and Prisma v6 Cleanup

- Scope:
  - Built API skeleton with Hono entry, shared error handling, auth middleware.
  - Implemented `POST /auth/register`, `POST /auth/login`, `GET /users/me`.
  - Removed duplicated `apps/api/packages/db` Prisma package and kept v6 only.
- Key Decisions:
  - Keep `register` flow without `auth.registration_open` gate in this phase.
  - Keep JWT as 7-day stateless token.
- Pitfalls and Causes:
  - `app.use('*', errorMiddleware)` did not give expected error responses for thrown errors in all cases; switched to `app.onError(...)`.
  - `.env` is not auto-loaded by `node dist/index.js`; runtime tests must export env vars explicitly.
  - Sandbox blocks socket binding and docker access; e2e verification requires escalated execution.
- Verification Commands and Results:
  - `pnpm --filter @taskflow/api build` passed.
  - Real API checks:
    - register/login/me success.
    - duplicate register 409.
    - wrong password 401.
    - no token 401.
    - inactive user access 403.
  - Data consistency check:
    - registration auto-created personal class and OWNER membership.
- Next Step:
  - Implement classes core endpoints and add a lightweight demo frontend.

## 2026-03-17 — Classes Core Endpoints

- Scope:
  - Implemented:
    - `GET /classes`
    - `POST /classes`
    - `POST /classes/join`
    - `GET /classes/{classId}`
    - `GET /classes/{classId}/members`
  - Added class serialization helpers and updated API test sample file.
- Key Decisions:
  - Invite code is generated by secure random bytes with collision retry.
  - `inviteCode` is hidden for `MEMBER` in class summary response.
- Pitfalls and Causes:
  - Need explicit permission semantics:
    - class exists + non-member -> 403
    - invite code not found -> 404
  - School restriction validation depends on both class `schoolId` and user `schoolId`.
- Verification Commands and Results:
  - `pnpm --filter @taskflow/api build` passed.
  - Real API checks:
    - create/join/detail/members success (200/201).
    - invalid invite 404.
    - duplicate join 409.
    - no token 401.
    - school mismatch 403.
- Next Step:
  - Build lightweight frontend demo for auth + classes flow.
