# MCP Server 实现外部AI工具的数据交互

1. MCP server 应当与现有的api对接。
2. MCP server 不需要实现全部API功能。目前仅为教师工作流程开发

## 功能列表
- 认证方法与流程
- 获取我管理的班级列表
- 获取我管理的任务列表
- 创建和发布任务、编辑任务
- 获取某个任务下的所有提交
- 获取模范提交，和尚未评分的列表
- 为提交评分和评语

## 自动评分功能详细说明

MCP server 只提供接口，如何评分应当由外部AI工具实现。

正确的设置文档和skills，在前端页面设计接入流程指导，帮助用户将mcp对接到他们本地的AI工具中。
