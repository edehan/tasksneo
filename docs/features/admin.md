# 管理员控制平面

`/admin` 控制平面是独立于普通用户体系的站点级管理入口，用于管理全局配置和执行系统级操作。

## 身份验证

所有 `/admin/*` 路由均由 `adminMiddleware` 保护，验证方式：

```
Authorization: Bearer <ADMIN_TOKEN>
```

`ADMIN_TOKEN` 只能通过服务器环境变量或容器配置文件设置，不能在 Web 页面中查看或修改。这样做的目的是将控制平面的鉴权逻辑与普通用户体系完全隔离，降低系统复杂度和攻击面。

`ADMIN_TOKEN` 只负责管理员身份验证，不承担系统配置加密职责。敏感配置项的数据库加密与解密应使用独立的 `SYSTEM_CONFIG_SECRET`。

---

## 系统配置

以下所有配置均存储在 `system_config` 表中，以键值对形式保存。

约定：

- 普通配置可明文存储。
- 敏感配置（如 `smtp.user`、`smtp.password`、`llm.api_key`）必须加密存储。
- 加密密钥来自运行时环境变量 `SYSTEM_CONFIG_SECRET`，而不是 `ADMIN_TOKEN`。

### 1. 站点基本信息

| 键 | 说明 |
|---|---|
| `app.title` | 站点标题，显示在前端界面 |
| `app.base_url` | 前端规范地址，用于邮件通知中的链接拼接 |

前后端服务地址是否允许通过控制平面修改，暂时保留讨论空间。若采用单机 Docker Compose 部署，后端地址由容器网络决定，通常不需要运行时配置。

### 2. 邮件发送配置

| 键 | 说明 |
|---|---|
| `smtp.host` | SMTP 服务器地址 |
| `smtp.port` | SMTP 端口（如 587） |
| `smtp.user` | SMTP 登录用户名（加密存储） |
| `smtp.password` | SMTP 密码（加密存储） |
| `smtp.from` | 发件人邮箱地址 |

**重要：提供测试配置功能**。流程是允许输入接收者邮箱，发送一封测试邮件。

### 3. AI 平台配置

| 键 | 说明 |
|---|---|
| `llm.provider` | 提供商标识，如 `openai`、`ollama` |
| `llm.base_url` | API 端点地址 |
| `llm.api_key` | API 密钥（加密存储） |
| `llm.model` | 模型名称，如 `gpt-4o-mini` |

### 4. 注册开关

| 键 | 值 |
|---|---|
| `auth.registration_open` | `'true'` 或 `'false'` |

值为 `'false'` 时，`/auth/register` 接口返回 403，拒绝新用户自助注册。

### 5. 通知配置

| 键 | 说明 |
|---|---|
| `notif.before_due_hours` | 截止前提醒的时间节点，逗号分隔，如 `'24,2'` 表示提前 24 小时和 2 小时各发一次 |

## 用户管理

控制平面提供基础的用户管理能力，不涉及班级和任务的管理。主要是禁止用户登录、修改用户基本信息（昵称电子邮件密码等），暂不支持删除用户，后续完善。

### 支持的操作

| 操作 | 行为 |
|---|---|
| 用户列表 | 分页返回所有用户，包含邮箱、昵称、学校、isActive 状态 |
| 停用用户 | 将 `isActive` 设为 false。用户无法登录，现有 Token 在下次请求时被中间件拦截 |
| 启用用户 | 将 `isActive` 设为 true |
| 重置密码 | 管理员输入新密码，后端更新 `user_credentials` 中 `provider = LOCAL` 对应记录的 `passwordHash` |

---

## 学校管理

管理员维护注册页面下拉列表中可选的学校列表。

| 操作 | 说明 |
|---|---|
| 查看学校列表 | 返回 `schools` 表所有记录 |
| 添加学校 | 向 `schools` 表插入新记录 |
| 删除学校 | 从 `schools` 表删除记录。关联用户和班级的 `schoolId` 字段通过 FK SET NULL 自动置空 |

学校名称视为不可变更。如需修改名称，删除原记录后重新创建。

---

## 控制平面界面

`/admin` 前端是独立的、最简化的管理界面，不与主应用共享导航结构和主题，仅保持基本的视觉一致性。表单布局即可满足需求，它是运维工具，不是面向用户的产品。
