## 查看班级任务列表

**触发**：点击侧栏中的班级名称。

**页面**：`/classes/[classId]`

- 顶栏面包屑：主页 > [班级名]

###  列表视图（默认视图）

**页面**：`/dashboard`

**用户看到**：
- 来自所有班级的全部任务，按截止时间升序排列（最近截止在最前）
- 已过期任务排在末尾（折叠，点击展开）
- 每行：班级颜色圆点、任务名、所属班级名、截止时间、状态徽章
- 顶部视图切换器：列表 / 甘特图（当前版本 v1 只做这两个视图）

### 甘特图视图

**页面**：`/dashboard/gantt`（或通过视图切换器切换）

**用户看到**：
- 横轴为时间（以周为单位，默认显示当前月 ± 2 周的范围）
- 纵轴为任务列表（按班级分组）
- 每个任务：一个横向色条，左端对齐 `startAt`（若无 startAt 则对齐 `createdAt`），右端对齐 `dueAt`
- 色条颜色来自所属班级的 `color` 字段，不透明度 0.85
- 今天的日期：一条红色竖线
- 依赖连线：若任务 A 被任务 B 的 `blockedBy` 引用，从 A 的右端到 B 的左端画一条带箭头的细线（`--border` 颜色，1px，SVG 实现）
- 若找不到 `blockedBy` 中的任务 ID（悬空引用），静默跳过，不报错

**交互细节**：
- 左右拖动时间轴（鼠标拖拽或触控板横向滚动）
- 点击任务色条 → 跳转到对应任务详情页
- v1 不支持拖拽调整时间，仅展示
