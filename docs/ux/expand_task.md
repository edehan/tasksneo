旅途 3：查看任务与提交作业（成员视角）

### 3.1 打开任务详情

**触发**：点击任务列表中的任务行。

**页面**：`/classes/[classId]/tasks/[taskId]`

**页面布局**：
- 最大宽度 720px，居中
- 顶部：任务名称（`display` 字号），截止时间，班级标签，状态徽章
- 正文区：Markdown 渲染（使用 `prose` class），图片可正常显示
- 附件区：任务附件列表，每个附件显示文件名、大小、下载按钮
- 去提交/修改提交（是班级成员）（Primary）create_submission.md
- 转到查看所有的提交（是班级管理员）（Primary）-- view_submissions.md

**已读记录**：
- 页面挂载时，前端在后台静默调用 `POST /tasks/:taskId/view`
- 此调用不阻塞页面渲染，失败静默忽略
- 调用成功后，侧栏/列表中该任务的状态徽章从"未读"变为"已读"（若之前是未读）

**前置任务提示**（若有）：
- 在正文上方显示一个 Banner："本任务依赖前置任务：[任务A]、[任务B]"
- 若前置任务均已提交：Banner 使用 success 样式（绿色）
- 若有前置任务未提交：Banner 使用 warning 样式（橙色），提醒用户先完成前置任务（但不硬性阻止）
