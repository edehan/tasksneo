进入注册页

**触发**：用户访问系统，无 Token，被重定向到 `/login`。点击"没有账号？注册"。

**页面**：`/register`

**用户看到**：
- 一个居中的卡片，卡片宽度约 400px，垂直居中于页面
- 卡片标题："创建账号"
- 表单字段（从上到下）：
  1. 邮箱（必填，`type="email"`）
  2. 密码（必填，`type="password"`，placeholder 提示"至少 8 位"）
  3. 昵称（选填，placeholder "留空则使用邮箱展示"）
  4. 学校（选填，下拉选择，数据来自 `GET /schools`，第一项为"不填写"）
  5. 学号（条件必填：选择学校后此字段变为必填，且出现红色星号）
- "注册"按钮（Primary，全宽）
- "已有账号？登录"链接

**交互细节**：
- 选择学校后，学号字段从 disabled/灰色变为 enabled，label 旁出现红色 `*`
- 清除学校选择后，学号字段重新变为 disabled
- 点击注册 → 按钮变为 loading 状态（禁用 + spinner）
- 成功 → 自动登录，跳转到 `/dashboard`，同时 Toast 提示"欢迎！你的个人空间已创建"
- 失败（邮箱已注册）→ 邮箱字段下出现红色提示"此邮箱已被注册"
- 失败（学号冲突）→ 学号字段下出现红色提示"此学校下该学号已存在"
- 注册关闭时 → 页面整体显示"注册功能当前未开放"提示，不显示表单
