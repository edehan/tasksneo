## 旅途 2：班级管理（成员视角）

### 2.1 通过邀请码加入班级

**触发**：侧栏底部"加入班级"按钮，或 Empty state 的"加入班级"按钮。

**用户看到**：一个 Dialog（模态框），标题"加入班级"，一个输入框（placeholder "输入邀请码"），"加入"按钮。

**交互细节**：
- 输入邀请码 → 点击"加入"
- 成功 → Dialog 关闭，侧栏立刻新增该班级条目，Toast 提示"已加入 [班级名]"
- 失败（邀请码无效）→ 输入框下显示"邀请码无效或已失效"
- 失败（学校不匹配）→ 显示"该班级仅限 [学校名] 的用户加入"
- 失败（已是成员）→ 显示"你已经是该班级的成员"

## 旅途 7：班级管理（管理员视角）

### 7.1 班级设置页

**页面**：`/classes/[classId]/settings`

**用户看到**：
- 基本信息：班级名称（可编辑）、描述（可编辑）、颜色选择（8 个预设颜色圆点，点选）
- 学校限制：下拉选择（不限制 / 具体学校）
- 邀请码：当前邀请码（`mono` 字体，有复制按钮）+ "刷新邀请码"按钮（Ghost）
- 刷新邀请码弹出 Confirm Dialog："刷新后旧邀请码立即失效，是否继续？"
- 危险区：红色边框区域，"删除班级"按钮（Destructive），点击弹出二次确认 Dialog

### 7.2 成员管理页

**页面**：`/classes/[classId]/members`

**用户看到**：
- 成员表格：头像、昵称/邮箱、角色 Badge、加入时间、操作列
- OWNER 行：角色 Badge 显示"所有者"，操作列有"转让所有权"（Ghost 按钮）
- ADMIN 行（对 OWNER 可见）：操作列有"降为成员"（Ghost）、"移除"（Ghost，Destructive 色）
- MEMBER 行（对 OWNER/ADMIN 可见）：操作列有"设为管理员"（Ghost）、"移除"（Ghost，Destructive 色）
- 当前用户自己的行：最后有"退出班级"按钮（若是 OWNER 则此按钮禁用，tooltip 提示"转让所有权后方可退出"）

**转让所有权流程**：
- 点击"转让所有权"→ 弹出 Dialog，下拉选择目标成员（过滤掉自己）
- 确认后：二次确认 Dialog "转让后你将成为 ADMIN，是否继续？"
