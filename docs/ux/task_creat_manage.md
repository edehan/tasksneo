## 旅途 4：发布与管理任务（管理员视角）

### 4.1 发布新任务

**触发**：进入班级页面后，若用户是该班级的 OWNER 或 ADMIN，顶部出现"发布任务"按钮（Primary）。

**页面**：`/classes/[classId]/tasks/new`

**页面布局**（上下两区域）：

**上方 — AI 解析区**：
- 一个大文本框（`textarea`，高度约 120px），placeholder "粘贴任务描述，AI 将自动提取关键信息..."
- "AI 解析"按钮（Secondary）
- 首次使用提示："支持自然语言描述，例如：下周五前提交算法作业，需要实现快速排序"
- 有一个提交附件的按钮，可以提交附件。（附件将属于该任务正文）用户点击结构化表单中的主按钮时，刚刚所写的内容和附件会被自动填写回正文编辑区。

**下方 — 结构化表单**：
- 任务名称（必填）
- 开始时间（日期时间选择器，选填）
- 截止时间（日期时间选择器，必填）
- 是否允许延迟提交（Toggle，默认开启；当前版本 v1 仅存储，不实际限制）
- 前置任务（多选，从当前班级已有任务中选择，选填）
- "编辑正文"按钮（Primary）--跳转到edit

**AI 解析交互**：
1. 用户在上方文本框输入内容，点击"AI 解析"
2. 按钮变为 loading 状态，文字"解析中..."
3. 解析完成：
   - 成功识别的字段自动填入下方表单（带高亮动画，如淡黄色背景 → 正常背景的过渡，持续 1 秒）
   - 未识别的字段保持为空
   - Toast 提示"已解析，请检查并确认"
4. 解析失败（网络或 LLM 错误）：Toast 错误提示"解析失败，请手动填写"，不影响表单

**验证规则**：
- 截止时间必填，且必须是有效的未来时间（在前端实时校验）
- 若截止时间早于开始时间，截止时间字段显示错误："截止时间不能早于开始时间"
- 点击发布时，名称和截止时间若为空，对应字段显示红色 error 样式

### 4.2 编辑任务

**页面**：`/classes/[classId]/tasks/[taskId]/edit`

富文本编辑器。如果是从创建任务过来的，正文和附件应该均已填入。
按钮将会是 发布任务 或 保存修改，取决于用户是从哪里进入的编辑页。

### 4.3 查看任务（管理员视角）

**页面**：与成员视角（expand_task.md）相同 URL，但内容不同

**管理员额外看到**：
- 任务详情顶部增加统计区：三个数字 —— 班级成员数 / 已读人数 / 已提交人数
  - 格式：`12 人 · 8 已读 · 5 已提交`
- 正文下方不显示"我的提交"区域，显示"查看所有提交"入口（次级链接或 Secondary 按钮）
- 右上角有"编辑任务"和"删除任务"操作（Ghost 按钮）

-- 转到查看所有的提交（管理员）-- view_submissions.md

### 4.4 删除任务

**触发**：任务详情页右上角"删除任务"按钮。

**交互**：弹出 Confirm Dialog：
- 标题"确认删除任务"
- 若无提交记录：正文"此任务将被永久删除，操作不可撤销"，确认按钮（Destructive）
- 若有提交记录：正文"此任务已有 [N] 份提交。删除后，任务内容和附件将被清除，但提交记录将保留。"，确认按钮（Destructive）
