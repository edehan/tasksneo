提交作业

**触发**： 点击任务详情下方的按钮后

**用户看到**：
- 标题继承任务名称，例如"提交：算法作业"
- 富文本编辑器（shadcn-editor）：支持文字、图片粘贴（自动上传）、代码块
- 附件上传区：拖拽或点击上传，显示已上传文件列表（文件名 + 大小 + 删除按钮）
- "保存草稿"按钮（Ghost）和"提交"按钮（Primary）
- 若已有提交记录：编辑器预填充上次内容，"提交"按钮变为"更新提交"

**交互细节**：
- 图片粘贴到编辑器：自动调用 `POST /tasks/:taskId/submissions/me/attachments`，上传成功后图片内联显示
- 文件上传：调用同一附件接口，上传进度用进度条显示
- 点击"提交"→ 调用 `PUT /tasks/:taskId/submissions/me`，成功后：
  - 状态徽章变为"已提交"
  - Toast 提示"提交成功"
  - "提交"按钮变为"更新提交"
- DDL 已过且 `allowLateSubmission = false` 且已有提交：不显示编辑器，显示"提交截止时间已过，无法修改"提示
